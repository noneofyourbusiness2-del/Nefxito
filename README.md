# Nefxito

Nefxito is a static AI-powered game tutorial website for learning how to install and run games on Chromebook and Android.

## Features
- Responsive HTML/CSS/JavaScript website
- Dark mode toggle
- Navigation menu
- AI-themed content sections
- Contact form with client-side feedback

## Publish Publicly
1. Create a GitHub repository named `nefxito.com` (or any name).
2. Push the project files to the repository.
3. Enable GitHub Pages from the repository settings using the `main` branch and `/` root folder.
4. Visit the public URL shown by GitHub Pages.
